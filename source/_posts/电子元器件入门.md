电子电路再复杂，拆开来看也就是几个基础元器件的组合。这篇笔记把常见元器件按「特点 → 作用 → 检测」的思路梳理一遍，重点放在**怎么识别**和**怎么用万用表判断好坏**上，方便后续看电路图、修家电时随时翻。

下面提到的检测方法，基本都靠一块万用表就能完成，所以先简单交代一下工具。

# 万用表

维修和检测元件最常用的工具，能测电压（V）、电流（A）、电阻（Ω）、电容（F），部分型号还能测二极管、三极管、通断蜂鸣。

- **电阻档**：测电阻、电感线圈、二极管正反向、线路通断
- **二极管档**：直接读出正向压降，判断二极管好坏最直观
- **电容档**：测电容量
- **电压档**：测电路工作电压，排查供电是否正常

> 用电阻档测量前，一定要先断开被测元件所在电路的电源，并给电容放电，否则读数不准甚至损坏表头。

# 电阻器

导体对电流的阻碍作用称为电阻，符号 **R**，单位**欧姆（Ω）**，常用单位还有 kΩ、MΩ（1 kΩ = 1000 Ω，1 MΩ = 1000 kΩ）。

常见电阻的图片

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.24bcyxfcffz4.webp)

## 主要参数

- **标称阻值**：元件上标注的阻值
- **额定功率**：能长期承受的最大功率，常见 1/8 W、1/4 W、1/2 W、1 W
- **误差精度**：实际阻值与标称值的偏差，常见 ±5%、±1%

## 应用

限流、降压、分压

- **限流**：串在 LED、三极管基极等回路里，把电流控制在安全范围
- **降压**：串接后分掉一部分电压
- **分压**：两个电阻串联，从中间取出需要的电压

## 串联与并联

- **串联**：R = R₁ + R₂ + …，阻值变大，分压
- **并联**：1/R = 1/R₁ + 1/R₂ + …，阻值变小，分流

## 色环电阻读数

四环电阻：前两环是有效数字，第三环是倍率（10ⁿ），第四环是误差。

| 颜色 | 数值 | 倍率 |
| --- | --- | --- |
| 黑 | 0 | 10⁰ |
| 棕 | 1 | 10¹ |
| 红 | 2 | 10² |
| 橙 | 3 | 10³ |
| 黄 | 4 | 10⁴ |
| 绿 | 5 | 10⁵ |
| 蓝 | 6 | 10⁶ |
| 紫 | 7 | 10⁷ |
| 灰 | 8 | 10⁸ |
| 白 | 9 | 10⁹ |

误差环：金 ±5%、银 ±10%、棕 ±1%、红 ±2%。

举例：**棕 黑 红 金** = 1、0 × 10²、±5% = **1 kΩ**。五环电阻则多一位有效数字，读数方法类似。

## 检测

用万用表的电阻档进行检测

- 测量值与标称阻值接近即正常；**远大于标称值**说明内部断路，**接近 0** 说明短路
- 指针式万用表换档后要先短接表笔**调零**，再测量
- 在路测量时结果会受并联支路影响，必要时拆下元件单独测

## 敏感电阻

包含压敏电阻、热敏电阻、光敏电阻、湿敏电阻、气敏电阻、力敏电阻、磁敏电阻等

这类电阻的阻值会随外界物理量（电压、温度、光照、湿度、气体、压力、磁场）变化，所以常被当作**传感器**用。

### 压敏电阻

特点：当外加电压都达到其临界值时，其阻值会急剧变小

作用：过压保护和抑制浪涌电流

检测：阻值都较大，因此检测压敏电阻主要是看其是否短路损坏

> 压敏电阻多和保险丝一起使用，保护负载

![image-20261008105605593](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.3zjwfkdcxsg0.webp)

### 热敏电阻

特点：阻值随温度变化而变化

作用：进行温度检测

检测：用万用表检测，给电阻加热，看阻值变化

按变化方向又分两类：

- **NTC（负温度系数）**：温度升高，阻值变小，最常见
- **PTC（正温度系数）**：温度升高，阻值变大，可作自恢复保险

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.2zsoijglqxk0.webp)

### 光敏电阻

特点：阻值会随入射光线的强弱而变化，光线越强阻值越小，光线越弱阻值越大

作用：进行光检测

常见于光控开关、路灯自动点亮、光电计数等场景。检测时可用手遮挡与手电照射对比阻值变化。

# 电容器

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.44bpxvpbu8m0.webp)

电容的主要参数有<font color="red">电容量</font>和<font color="red">耐压</font>

单位**法拉（F）**，常用 μF（微法）、nF（纳法）、pF（皮法）。

## 主要参数

- **电容量**：储存电荷的能力
- **耐压**：能承受的最高工作电压，超过会击穿
- 其他：温度系数、漏电流、ESR

## 常见类型

| 类型 | 特点 |
| --- | --- |
| 电解电容 | 容量大、**有极性**，长脚为正、短脚为负，外壳标有负极条 |
| 陶瓷电容 | 体积小、无极性、高频特性好，多用于去耦 |
| 钽电容 | 容量密度高、有极性，注意不要反接 |
| 薄膜电容 | 稳定性好、无极性，多用于谐振、耦合 |

特点：隔直流通交流

补充：电容两端**电压不能突变**，所以常用于储能和滤波；充放电需要时间，这是它区别于电阻的关键特性。

作用：耦合、旁路滤波、移相、谐振

- **耦合**：传递交流信号，隔断前后级直流工作点
- **滤波**：滤除纹波，让电压更平滑
- **旁路/去耦**：给高频干扰提供低阻通路

## 串联与并联

规律与电阻**相反**：

- **并联**：C = C₁ + C₂ + …，容量变大，但耐压取最小值
- **串联**：1/C = 1/C₁ + 1/C₂ + …，容量变小，耐压提高

## 检测

用万用表的电容挡进行检测

- 电容量与标称值接近即正常；偏差过大或读数为 0 说明失效
- 用电阻档测时，指针应有**先摆后回**的充电过程，指针不动说明开路，指针不回落说明短路
- 测量前必须**先放电**，电解电容尤其注意极性

# 电感器

储存电能的元件

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.41amepz1cx60.webp)

单位**亨利（H）**，常用 mH、μH。

特点：通直流阻交流

补充：电感**电流不能突变**，断电瞬间会产生反向感应电动势（楞次定律），这是开关电源和继电器线圈需要续流二极管的原因。

作用：分频、滤波、谐振、磁偏转

常见于滤波器、LC 谐振回路、开关电源储能、扬声器分频器等。

检测：万用表电阻档初步检测，是否短路、断路、绝缘不良等情况

- 正常线圈直流电阻很小（几欧到几十欧）
- **无穷大**说明断路，**接近 0 且短路**要警惕匝间短路
- 有铁芯的还要检查绕组与铁芯之间是否绝缘不良

# 变压器

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.1xdy8g2hwdds.webp)

由初级绕组、次级绕组和铁芯（或磁芯）组成，靠**电磁感应**传递能量。

特点：传输交流隔离直流，并可同时实现电压变换、阻抗变换、相位变换

核心关系：**电压比 = 匝数比**，即 U₁/U₂ = N₁/N₂；电流比则相反，功率基本守恒（忽略损耗）。

作用：电压变换

常见类型：电源变压器、音频变压器、高频/开关变压器、隔离变压器。

检测：万用表进行基本检测

- 分别测初级、次级绕组电阻，判断是否断路
- 测绕组与铁芯之间电阻，判断绝缘是否良好（应为无穷大）
- 通电后测次级输出电压是否符合预期

# 晶体二极管

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.na55n52j3m8.webp)

核心是 **PN 结**，具有单向导电性。

特点：单向导电，一般情况下只允许电流从正极流向负极

- 正向导通时有固定压降：**硅管约 0.6~0.7 V，锗管约 0.2~0.3 V**
- 反向截止，但存在很小的反向漏电流

作用：整流、检波、开关

按用途可分为：整流二极管、稳压二极管、开关二极管、发光二极管（LED）、光电二极管、肖特基二极管等。

检测：电阻档，正反向电阻的阻值应该相差很大

- 用**二极管档**更直观：正向显示压降（如 0.5~0.7），反向显示溢出（1 或 OL）
- 若正反向都为 0 说明击穿短路，都为无穷大说明开路
- **极性判断**：有色环（或符号箭头指向）的一端为**负极**

# 晶体三极管

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.2ln4o5nys580.webp)

三个电极：**基极 b、集电极 c、发射极 e**，分 **NPN** 和 **PNP** 两种类型。

特点：放大电流

电流放大系数 **β = Ic / Ib**，即基极的小电流控制集电极的大电流，这是「放大」的本质。

三个工作区：

| 工作区 | 条件 | 用途 |
| --- | --- | --- |
| 截止区 | 发射结反偏 | 相当于断开的开关 |
| 放大区 | 发射结正偏、集电结反偏 | 信号放大 |
| 饱和区 | 发射结、集电结均正偏 | 相当于闭合的开关 |

作用：放大、振荡、电子开关、可变电阻、阻抗变换

检测：用二极管档分别测两个 PN 结（b-e、b-c），正向有压降、反向无穷大即正常；再结合两个结的方向判断是 NPN 还是 PNP。

# 继电器

![](https://cdn.jsdelivr.net/gh/hfshaobing/picx-images-hosting@master/20261008/image.3w44qm3h7xm0.webp)

由**线圈**和**触点**两部分组成，线圈通电产生磁场，吸合衔铁带动触点动作。

触点分为：**常开触点 NO**（不通电时断开）、**常闭触点 NC**（不通电时闭合）、**公共端 COM**。

作用：间接控制和隔离控制

价值在于**用小电流、低电压控制大电流、高电压**，同时把控制回路和负载回路电气隔离，避免强电干扰弱电。

主要参数：线圈额定电压（5 V、12 V、24 V 等）、触点容量（可承受的电压电流）。

检测：

- 测线圈两端电阻，判断线圈是否断路
- 手动或通电吸合时，测 NO/NC 触点通断是否正常

# 元器件速查

| 元件 | 特点 | 主要作用 | 检测方法 |
| --- | --- | --- | --- |
| 电阻器 | 阻碍电流，阻值固定 | 限流、降压、分压 | 电阻档，比对标称值 |
| 敏感电阻 | 阻值随外界物理量变化 | 传感、保护 | 改变外界条件看阻值变化 |
| 电容器 | 隔直流通交流，电压不能突变 | 耦合、滤波、谐振 | 电容档；电阻档看充放电 |
| 电感器 | 通直流阻交流，电流不能突变 | 滤波、谐振、扼流 | 电阻档，测通断 |
| 变压器 | 电磁感应传能，隔离直流 | 电压/阻抗/相位变换 | 测绕组通断与绝缘 |
| 晶体二极管 | 单向导电 | 整流、检波、开关 | 二极管档测正反向 |
| 晶体三极管 | 电流放大 | 放大、开关、振荡 | 测两个 PN 结 |
| 继电器 | 线圈控制触点 | 间接控制、隔离控制 | 测线圈电阻与触点通断 |

# 小结

- 判断一个元件好坏，核心都是**和它的正常状态做对比**：电阻看阻值、电容看容量和充放电、二极管看单向性、三极管看两个 PN 结。
- 敏感电阻的「变化」才是它的正常状态，测之前先想清楚该给它什么条件。
- 维修时遵循「先断电、先放电、先目视（鼓包、烧焦、变色）」的顺序，再上表测量。
