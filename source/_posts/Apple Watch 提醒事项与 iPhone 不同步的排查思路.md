# 问题现象

手机「提醒事项」里已经处理掉的事项，Apple Watch 上还挂着；有时候反过来，手表上划掉的东西手机没反应。两台设备各说各话，重启一次好了半天，过几天又来。

这类问题最坑的地方在于：**你看到的"不同步"可能根本是两个不同的问题**，而大多数人一上来就重置手表，方向错了，白折腾。

# 先纠正一个误解：取消提醒 ≠ 删除事项

动手之前先确认你操作的是哪一种：

| 你的操作 | 正常表现 |
| --- | --- |
| 关掉某条事项的提醒时间 / 位置提醒 | 事项本身还在，只是不会再响；手表上当然也还看得见，**这是对的，不是 bug** |
| 把整条事项删除 | 手机、iCloud、手表三处都应该消失 |
| 把事项标记为完成 | 默认从列表里隐藏，但换个"已完成"视图还能看到 |

如果只是"取消了提醒"，手表上仍然有这条事项，那是设计如此。真正需要排查的是**整条事项删了、手表还在**这种情况。

# 同步链路：手表其实是个镜像

理解这一点，排查会快很多：

- **iCloud** 是数据最终存放的地方，网页版 `iCloud.com` 看到的就是云端真相；
- **iPhone** 把本地改动上传到 iCloud，同时把云端改动下载回来；
- **Apple Watch** 上的提醒事项基本是跟着 iPhone 走的镜像，它自己很少直接和云端对话。

所以"手机删了、手表还在"只有两种可能：要么 iPhone 的删除压根没上传成功（云端还是旧的），要么云端已经删了但 iPhone→手表 这条推送堵住了。**先确定是哪一种，再动手。**

# 第一步：确定哪边才是"对的"

浏览器打开 [iCloud.com](https://www.icloud.com) → 提醒事项，看那条事项还在不在。这一步决定了后面完全不同的两条路径。

| 网页上的状态 | 说明 | 处理方向 |
| --- | --- | --- |
| 已经没了 | iCloud 是对的，手表只是没刷新 | 情况 A：修手表 |
| 还在 | 手机的删除没上传成功，手表显示的是"对的" | 情况 B：修 iPhone 与 iCloud 的同步 |

很多人卡在这里：以为是手表坏了，其实是手机端删除从来没生效过，重置手表当然没用。

# 情况 A：网页上也删掉了，只有手表落后

按从轻到重的顺序来，多数情况前两步就解决了：

1. **两台设备都重启一次。** 别嫌土，watchOS 的后台同步进程卡死很常见。
2. **强制退出提醒事项。** iPhone 上从底部上滑并停住，把提醒事项卡片上滑关闭；手表上打开提醒事项 → 长按侧边按钮直到出现关机滑块 → 松开，再长按数码表冠，App 会被强杀。
3. **重置手表同步数据。** 手机 Watch App → 我的手表 → 通用 → 重置 → **重置同步数据**。这只会清掉手表上的同步副本（联系人、日历、提醒等）再重新拉取，**不会动 iPhone 上的任何数据**，相对安全。
4. **检查连接状态。** 蓝牙和 Wi-Fi 正常、都没开飞行模式；重点是**两台设备都关掉低电量模式**，它会让后台同步停摆。
5. **看存储空间。** iPhone 或手表快满的时候，同步会静默失败，不报任何错。

# 情况 B：网页上还在，问题在 iPhone 上传

这种情况手表是无辜的，它只是如实转述了云端的数据。按发生概率排查：

1. **iCloud 里的提醒事项开关被关了。** 设置 → 你的名字 → iCloud → 显示全部 → 提醒事项。这是最常见的元凶，开关一关，手机就退化成只用本地副本，删改全都不上云。如果是关的，打开它，但注意手机会从 iCloud 重新下载，可能出现重复列表，需要合并一下。
2. **网页端和手机不是同一个 Apple ID。** 网页右上角确认账号，手机在 设置 → 你的名字 顶部看邮箱。账号不一致，就会出现"手机上删了、网页上还在"的假象。
3. **iCloud 储存空间满了。** 设置 → 你的名字 → iCloud → 管理账户储存空间。满了之后提醒事项的同步会直接停掉，而且不报错。
4. **网络或时间异常。** 关掉 VPN 和代理，开关一次飞行模式，确认"日期与时间"是自动设置。然后重启 iPhone、强杀提醒事项、重新打开下拉刷新。
5. **强制重连一次同步。** 设置 → 你的名字 → iCloud → 显示全部 → 提醒事项，关闭，等 10 秒再打开。关闭时提示"将从 iPhone 移除"是正常的，数据会从 iCloud 重新下载——**代价是那条已删的事项会重新回到手机上**，所以等同步恢复正常后，再删一次才会真正上传。
6. **检查列表所属账户。** 设置 → 提醒事项 → 账户。放在"我的 iPhone"本地列表里的事项既不上 iCloud 也不进手表；Gmail、Exchange 账户的列表同步行为也和 iCloud 不同。
7. **更新 iOS。** 提醒事项升级过数据库格式，版本落后时偶发"只收不发"。

如果只是想赶紧让手表干净，还有个不讲道理但有效的办法：**直接在 iCloud.com 上手动删掉那条**。网页端是云端权威，删完手机和手表都会跟着消失。代价是手机端的同步链路还是坏的，下次照样发生。

# 一个快速判断测试

不确定是整条链路断了，还是单条事项的状态异常，做个测试最直接：

在 iPhone 上新建一条测试提醒（比如"同步测试"），等十秒，看它有没有出现在 iCloud.com 上。

- **新建的也不同步** → 是整条 iCloud 提醒事项同步断了，按情况 B 逐条查。
- **新建的能同步、只有删除不同步** → 少见，多半是那条事项本身状态异常，网页端删掉即可，不必深究。

修好之后再验证一遍：手机新建 → 看网页有没有 → 网页删掉 → 看手机有没有消失。三步都通，链路才算真的通了。
